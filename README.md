# Basic-Port-Scanner
Basic Port Scanner - Python Project
===================================

Description:
------------
This is a basic port scanner written in Python. It allows users to scan a target host for open TCP ports within a specified range. The scanner attempts to connect to each port and reports which ones are open.

Features:
---------
- Scans a target IP address or hostname.
- Allows user-defined port range.
- Identifies open TCP ports.
- Basic error handling for invalid inputs and unreachable hosts.

Requirements:
-------------
- Python 3.x
- Works on Windows, Linux, and macOS

How to Use:
-----------
1. Clone or download this repository.
2. Open a terminal or command prompt.
3. Run the script using: Python3


4. Follow the prompts:
- Enter the target IP address or domain name.
- Enter the starting and ending port numbers.


Note:
-----
- Running this script may require administrative or root privileges depending on your system.
- Only scan hosts you own or have permission to scan.
